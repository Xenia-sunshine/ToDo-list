4. В прошлый раз не обратил внимание, зачем модели Login и Registration?
5. Логика работы с задачами должна быть совершенно иная:
- Пользователь может создать задачу только себе
- Пользователь видит только свои задачи
- Для просмотра не надо вводить id

Ответ на 4 задание:
модель Login - модель Eloquent, которая взаимодействует с таблицей в базе данных  содержащей информацию о пользователях.
Вместо модели User,используется модель Login.
Модель Registration была удалена-не используется.
